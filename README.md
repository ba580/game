# 🏒 Hockey Official: Road to the Show

A browser-based hockey officiating career simulator.

## Gameplay
Start as a U8 official and work your way through U10, U12, U14, U16, Varsity, Juniors, College Development and College Official.

During each game:
- Watch the rink
- Make Good Play, Offside, Icing, or Penalty calls
- Build accuracy and reputation
- Earn game pay
- Gain XP
- Unlock higher levels

Keyboard:
- G = Good Play
- O = Offside
- I = Icing
- P = Penalty

## GitHub Pages
Upload `index.html` to a GitHub repository, then:
Settings → Pages → Deploy from a branch → main → /(root) → Save.
